Coloca aquí tus imágenes con estos nombres exactos para que la página las muestre:

- sakura.png   (imagen principal)
- abanico.png  (imagen secundaria)
- fondo.jpg    (imagen de fondo en la cabecera)

Recomendaciones:
- fondo.jpg: 1200×600 o mayor, formato JPG
- sakura.png y abanico.png: PNG con fondo transparente o 800×800

Si quieres, sube los archivos usando la app de GitHub o el navegador y reemplaza estos nombres.
